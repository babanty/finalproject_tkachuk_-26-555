# Ход работы

- Этап 1: пакет, окружение uv, проверки и минимальный CLI реализованы. Python 3.12.15 закреплён в `.python-version`; настоящий Git-репозиторий находится только в корне проекта. Проверены `uv sync --locked`, Ruff, 3 smoke-теста, `uv build` и три пути запуска CLI.
- Этап 2: реализованы User/Wallet/Portfolio, иерархия и реестр валют, доменные исключения и общие валидаторы. Добавлены 122 тестовых случая для учётных данных, сумм, валют и оценки портфеля. Адресный запуск `uv run pytest -q tests/unit` прошёл: 122 passed. Перед коммитом выполняется полный gate для окончательного состояния кода.
- Этап 3: реализованы SettingsLoader и DatabaseManager как singleton, пакетная конфигурация, строгий JSON, сериализация и атомарная запись, общая межпроцессная блокировка и откат обычной ошибки сохранения аккаунта. Добавлены пустые образцы данных и тесты конфигурации, отказов записи и Windows spawn. Первый адресный прогон хранилища прошёл: 68 passed; расширенный набор и полный gate выполняются перед коммитом.
- Этапы 4–12: не начаты.

Аккаунты ExchangeRate-API и CoinGecko зарегистрированы. Ключи хранятся в локальном игнорируемом `.env`; реальная сеть пока не проверялась. Значения ключей в отслеживаемые файлы не добавляются.

Следующий шаг: после локального коммита этапа 3 — этап 4, регистрация, login и интерактивный CLI. Сообщения новых коммитов пишутся на русском. Пользовательскую запись демонстрации готовим отдельным шагом в конце проекта.
