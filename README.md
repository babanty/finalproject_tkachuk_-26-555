# ValutaTrade Hub

Учебное консольное приложение для виртуального валютного кошелька и отслеживания курсов. Реализация ведётся последовательно. Доступны доменные модели пользователей, кошельков и портфелей, иерархия валют и их валидация; CLI пока показывает справку. Пользовательские команды будут подключены на следующих этапах.

## Требования

Windows 11, Git Bash и `uv`. Проект фиксирует Python 3.12 в `.python-version`; `uv` может установить его автоматически. Глобальная установка Python и активация `.venv` вручную не нужны.

Команды из корня `finalproject_tkachuk_М26-555` в Git Bash:

```bash
uv sync --locked
uv run valutatrade --help
uv run python -m valutatrade_hub --help
uv run python main.py --help
```

## Проверки

```bash
bash scripts/check.sh
uv build
```

Перед каждым локальным Git-коммитом выполняются Ruff и полный набор тестов. Реальные JSON-данные приложения, логи и `.venv` не отслеживаются Git. Инструкции по кошельку, настройкам курсов и Parser Service будут дополнены на соответствующих этапах.

## Доменные модели

`core/models.py` содержит `User`, `Wallet` и `Portfolio`. Пароли хранятся как SHA-256 с индивидуальной солью; открытый пароль в модели не сохраняется. Кошельки принимают конечные числовые значения и отклоняют отрицательный баланс, булевы значения и некорректные суммы. Неудачное изменение оставляет прежнее состояние.

`core/currencies.py` определяет `Currency`, `FiatCurrency`, `CryptoCurrency` и `get_currency()`. Поддерживаются USD, EUR, GBP, RUB, BTC, ETH и SOL. Неизвестный код и неверный формат кода имеют разные ошибки. Капитализация в реестре пока не загружена и отображается как `N/A`.

Для оценки `Portfolio` получает функцию `rate_provider(from_code, to_code)`, возвращающую положительный числовой курс. В текущих тестах используются фиксированные учебные котировки. Модели не обращаются к JSON-файлам или API самостоятельно. Подробности — в [описании архитектуры](docs/architecture.md).
